# tutorial_LangGraph

```
ユーザー発話
    │
    ▼
classify_intent
    │
    ├─ book_restaurant ──► extract_slots ──► respond
    │                           │
    │                           └─ スロット埋める / 完了なら予約ID発行
    │
    ├─ cancel_booking ──────────► respond
    │         │
    │         ├─ 途中キャンセル → スロットリセット + 「中止しました」
    │         └─ 予約後キャンセル → 予約IDでキャンセル処理
    │
    ├─ weather ─────────────────► respond（モック天気応答）
    │
    └─ other ───────────────────► respond（汎用応答）
```

```
あなた: 明日の夜4人で予約したい
ボット: ご希望の時間を教えてください（例: 19時）

あなた: やっぱりやめます          ← 途中キャンセル
ボット: 承知しました。予約手続きを中止しました。...

あなた: 明日の夜4人で予約したい
ボット: ご希望の時間を教えてください
あなた: 19時
ボット: ご予約のお名前を教えてください
あなた: 田中
ボット: ご予約を承りました！ 予約ID: A1B2C3D4 ...

あなた: キャンセルしたい          ← 予約後キャンセル
ボット: 予約ID `A1B2C3D4` のキャンセルを承りました。...

あなた: 今日の天気は？
ボット: 今日の天気は晴れです。気温は28度前後で...
```

```
あなた: 明日の19時に4人で田中で予約したい
→ extract_slots が一度に
   date="明日", time="19時", party_size=4, name="田中"
→ 全部埋まるので completed=True → 予約完了メッセージ

あなた: 明日の夜予約したい
→ date="明日" だけ埋まる
→ 次に time を質問

あなた: やっぱりキャンセル
→ 途中キャンセル分岐

```
